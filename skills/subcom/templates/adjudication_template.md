## DHET eligibility checklist

- **C1 — Publisher / ISBN: PASS / FAIL / UNCERTAIN.** One-sentence finding quoting the evidence (e.g. ISBN from the copyright page, publisher name).
- **C2 — Length: PASS / FAIL / UNCERTAIN.** State the substantive page count (excluding references, bibliography, index, appendices) vs. the 60-page minimum.
- **C3 — Peer review evidence: PASS / FAIL / UNCERTAIN.** Describe the evidence: named reviewers? full reports? publisher confirmation letter? generic template? proposal-only?
- **C4 — Originality / new knowledge: PASS / FAIL / UNCERTAIN.** Summarise the author's originality claim and any PhD/prior-publication disclosure.
- **C5 — Not an excluded category: PASS / FAIL / UNCERTAIN.** Confirm it's not a textbook, handbook, reference, festschrift, translation, etc.
- **C6 — Scholarly contribution (academic merit): see score below.**
- **C7 — Documentation complete: PASS / FAIL / UNCERTAIN.** Confirm required documents are on file (book PDF, 500-word justification, plagiarism declaration, English summary if non-English, late-submission motivation if applicable).

## Scientific contribution score: {X} / 5

Two to four sentences of justification, grounded in quoted evidence from the submission. Focus on academic merit: originality, depth, significance, embedding in literature, methodological rigour. Quote the TOC or introduction if helpful. Award 5 sparingly — most genuinely scholarly works are a 4.

---

## Recommendation to committee

**Approve / Refer for deliberation / Reject.** One short paragraph on what the committee should verify, any item worth a minute of discussion, and — if relevant — what additional evidence would resolve an UNCERTAIN. Do not hide concerns; surface them clearly so the committee can decide.
